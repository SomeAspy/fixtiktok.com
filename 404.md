Uh-Oh! It seems the CloudFlare Worker has failed for one reason or another. Most
likely the ratelimit has been hit. If you see this error for more than 24 hours,
[open an issue!](https://github.com/SomeAspy/fixtiktok.com/issues/new) ``` ```

### Logic implementation for this error page:

```caddyfile

fixtiktok.com *.fixtiktok.com {
        tls {
                dns cloudflare
        }

        @bots {
                header User-Agent *Discordbot*
        }

        handle @bots {
                header Retry-After "3600"
                respond "Service Temporarily Unavailable" 503
        }

        @root path /
        redir @root https://github.com/SomeAspy/fixtiktok.com permanent

        @has_uri not path /
        redir @has_uri https://error.fixtiktok.com/ temporary
}

```
